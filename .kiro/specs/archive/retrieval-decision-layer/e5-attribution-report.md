## 實驗③｜快照灰帶密度：灰帶假說在仲裁點被推翻

a1–a3 三輪 170 個仲裁點快照（`usage_events.decision_snapshot->kb_top1_final`）分佈：

```
<0.73                    0
0.73–0.75（面向門檻下緣）   3   （1.8%）
0.75–0.77（面向門檻上緣）   0
0.77–0.85               16
≥0.85                  151   （88.8%）
±0.02 貼 KB 門檻 0.65： 0/170（0.0%）
```

- **決策點分數幾乎全部 ≥0.85**——關鍵字/意圖加成把 final 分數推到飽和區（與既有
  「加成飽和塌陷」盤查結論一致）。research.md 的「全語料泡在門檻灰帶（中位 0.50–0.53）」
  量測的是 **raw 向量/rerank 分數**，兩者都對，但**路由翻動發生在決策點**，決策點沒有
  分數-門檻灰帶。
- **對 P1 任務 2.4 校準定界的直接含義**：灰帶不能用全域分數帶（0.55–0.75 種子）在
  production final 分數上直接定界——飽和區內「進面向 vs 直答」的分界特徵是
  **top1 身分（錨點 vs 實答知識）與近分候選排序**，不是分數高低。校準集定界時應以
  「決策點特徵」重新萃取；此為報告建議，design.md 是否修訂待 P1 開工時議。

**同輪跨輪次分數抖動**：56 個三輪皆有快照的輪中 53 輪位元級相同；3 輪非零，最大
Δ=0.0105（#18 T2）——且該差來自 **top1 是不同知識**（見實驗①'），不是同知識分數抖動。

## E-5 目標上限提案（R8.2，請業主核定）

**驗收指標定義（先定標準）**：
- 分類器：`rc-v1+ad8c415d`（或其升版，升版時基準同步重測）；FORM 以結構化欄位判定。
- 母體：凍結語料 routing_determinism 母體 **104 輪**（107 − testcase 3 輪；
  noise_manifest.json `usage_rules.routing_determinism_e5`）。
- 量測法：P1 完成後同碼同輸入全量 **3 輪**（cache off），取 3 個 pairwise 不一致輪數的
  **中位數**。

**提案上限：中位數 ≤ 3/104（≈2.9%）**。

依據（歸因對映 P1 機制，非拍腦袋減半）：
1. 級聯項（10 樣本 census 中翻動輪的 6/13 為級聯）由 C3 逃生門＋再進場抑制（審查修訂 2）
   直接封殺——初翻點被詞表決定性攔截後，一次黏著 ×5 的放大器拆除。
2. #18 型 top1 身分翻（1–2 輪/對照）由任務 2.1 識別碼訊號「knowledge 型帶編號→偏向直答」
   決定性規則蓋掉——這型從「低頻翻動」變「規則固定」。
3. 殘餘不可壓項：無知識灰區 ANSWER↔FALLBACK（#11 尾段型，相關性把關 LLM 兜底所在，
   P1 無對應機制）＋rewrite 聯集偶發——保守估 2–3 輪/對照，故上限取 3 不取 2。
- **輔助觀測指標（不作 gate）**：clarify 增強尺中位（現況 19/107）隨逃生門上線應下降，
  收案報告呈報趨勢，不設數字關卡。
- 本上限**核定後寫入 design.md，不得放寬**（R8.2）。若 P1 執行中發現上限不可達，
  依 R2.2 帶證據退回重議，不得靜默調高。

## 對 P1 設計的三點修正性輸入

1. **逃生門的主戰場是「切換題」不只是「拒絕句」**：#07/#10/#21 的初翻點都是使用者
   換了主題而面向不放手——C3 的「主題不符」詞表/判定權重應不低於「拒絕」詞表。
2. **識別碼訊號優先序應高於錨點**：#18 T2 的正解知識就在庫（0.9392 可退場），輸給空答案
   錨點（0.9497）。knowledge 型帶編號 → 直答的規則要在「錨點奪 top1」時也生效
   （即以 top-3 內是否存在實答知識判斷，不只看 top1）。
3. **灰帶校準（2.4）不能沿用全域分數帶**：決策點分數飽和（88.8% ≥0.85），
   灰帶特徵應改取「top1 是否錨點／top1-top3 內實答知識存在性／面向進場 vs 直答分界」。
