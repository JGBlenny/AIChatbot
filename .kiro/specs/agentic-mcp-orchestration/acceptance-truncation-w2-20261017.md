## 三、非目標（相對規則收窄的部分與理由）

- 備援模型（W-R3）。
- 用 `frequency_penalty`／`presence_penalty` 等參數降低發生率：Bedrock 是否接受未查完，而且不服務本片規則。
- 對話歷史改以 JSON 形式呈現（0-4「刪上一輪回覆」組也有效）：刪除會丟上下文，改呈現方式未量測；W-R7 已承接對症修法。
- 意圖判斷呼叫（輸出上限 800）：本片只處理主模型呼叫。
