## 0. 結論先講

`minimal` 把延遲與成本拉回可上線區間（不含 API 掛住的回合 p50 3.8 s／p95 9.5 s；$0.0037/回合），而且 A 層翻轉 **6/10** 首次跨過 ≥5 的門——四輪以來（1→3→4→6）第一次過。但推理關掉之後模型輸出品質掉了三塊，每一塊都是預登記門或鐵則：
1. **引用標記混入 JSON 碎片**：37 次嘗試被 Verifier 以 `SCHEMA:ref_invalid` 拒（52 只有 1 回合），其中 32 次 ref 字串尾巴帶著 `]},{`、`kind` 之類結構碎片——模型在 strict schema 下把陣列邊界寫進字串。`budget_exhausted` 因此 35 → **42**，首拒因 `SCHEMA` 17 居首。
2. **敏感層漏 1**（D-02「租客的資料你們怎麼處理」rep1 被答成註冊資料蒐集說明，第二句「身分綁定」兩判者皆判無據）——預登記「漏 ≥1 即命中」，且 4.4b／51／52 三輪都是 0。
3. **無據率回升**：一致子集 67 句無據 **7（10.4%）**，52 是 0/117；E-03「可以延長時效嗎」兩回合答「可以延長」（正本 `contract-esign-flow`【時效】寫 72 小時逾期失效需重發），是本專案第一次量到**極性反轉的捏造**進了放行句。
另外 C 層（已能答）從 15/15 掉到 **9/15**、對照組 B-01 首次被硬答（52 是 `ask`），方向一致：`minimal` 換來速度，賠掉的是輸出契約遵從與謹慎度。結論：**gpt-5-mini 的 `minimal` 不能直接上線；`low` 未量。** 下一刀在 §5。

## 2. 延遲與 API 掛住（工具面事實）

- 147 回合中 **13 回合**至少撞一次 OpenAI 端 60 s 無回應：10 回合一次逾時後重試成功（延遲 62–67 s），**3 回合連重試都逾時**（≈182 s）→ 記 `provider_error`（E-02 rep0、E-05 rep1、C-04 rep2）。52 用 SDK 預設 600 s 時也有 1 回合 628 s，不是 `minimal` 造成，是 API 端現象；比率 8.8% 回合，上線前要量 gpt-4o-mini 是否同率（51／4.4b 兩輪 p95 4 s、max 未見 >60 s ⇒ 疑似 gpt-5 系列端點特有）。
- 排除掛住回合：p50 3.8 s、p95 9.5 s；52 為 17.4／38.1 s。$0.55／147 回合＝$0.0037／回合（52：$0.0056）。

## 3. `SCHEMA:ref_invalid` 的形狀（新病灶）

198 次嘗試中 37 次 `ref_invalid`；逐一看 ref 字串：32 次帶 JSON 結構碎片（例 `[87dc…:outline:prospect/C/contract-modify-after-sign§0]},{`、`…§5]},{`＋`kindainterrupted`），5 次其他畸形。4.4b 的畸形是三段式（丟 nonce），52 幾乎歸零；本輪是**字串邊界錯**——推理關掉後 strict schema 的陣列收尾被寫進字串。這不是提示詞能治的（裁定 13 也不准加例子）；落點是輸出契約：(a) `reasoning_effort=low` 是否已消失（一量即知，$0.6 級）；(b) runtime 對 ref 欄位做**去尾**正規化（只截掉 `]` 之後的碎片，不補造）——屬 DSP-029a 範圍，需先量誤放。

## 5. 待業主裁

1. **判定**：`minimal` 過翻轉門但敗在契約遵從與謹慎度（`SCHEMA` 37、敏感漏 1、無據 10.4%、C 層 15→9）；本輪記為「第 4 基線（推理力度軸）」，4.4 不打勾。
2. **下一刀（建議順序）**：(a) 同組態改 `AGENT_REASONING_EFFORT=low` 再量一次（$0.6–0.8 級；看 `SCHEMA` 碎片、敏感漏、無據是否回到 52 水準而延遲落在 6–10 s）——這是三軸（模型／力度／尺）裡最便宜的一格；(b) 若 `low` 仍帶碎片 ⇒ 立 DSP-029a 的 ref 去尾正規化案（先量誤放）；(c) Verifier 極性／覆蓋尺離線量測案維持（52 §5-2b）。⛔ 不建議直接上 `minimal`。
3. **API 掛住 8.8%**：上線前需量 gpt-4o-mini 同題集是否同率；若 gpt-5 端點特有，`OPENAI_TIMEOUT_S` 應設 30 s 級、且 runtime 對 `APITimeoutError` 要有回合級降級（現在只有評估工具有）。
4. 累積待裁不變：H5 邊界尺（整數線 vs 同批對照）、H3 兩臂低於 round9 是否立案、下次凍結 E-01／02／05 重標＋「答到」限 `kind=answer`。
