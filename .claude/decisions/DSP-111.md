# DSP-111

以下為 2026-10-24 建立時的原文與依據。

**決定**：AI 客服的照片辨識與文件讀圖（含收據）改用 Bedrock 東京（ap-northeast-1）的 `qwen.qwen3-vl-235b-a22b`。設定如下：

- 送圖前等比縮到長邊 2000 像素。
- 呼叫時帶 `"serviceTier": {"type": "flex"}`。

本決定取代 DSP-080 裡「照片／收據另選開源視覺模型（候選 Gemma 3 27B）」那一句；DSP-080 其餘內容不變。
本決定只定模型和送圖參數，程式什麼時候切換、怎麼切換，另外開一片處理。

**業主原話**（2026-10-23）：

- 「Qwen3 VL 235B 為 評估的決定 縮圖 和 flex」
- 「不用測試 暫定 flex 可接受延遲」

**被否決的替代方案**：

- **Gemma 3 27B**（DSP-080 原本的候選）：東京區呼叫一直沒有回應，60 秒逾時；業主同事的帳號也卡到 5 分鐘。
- **Ministral 3 14B、Mistral Large 3、Nemotron Nano 12B v2 VL**：讀單據 5 欄的正確率分別是 83.3%、74.1%、70.4%，Qwen 是 92.6%。Mistral Large 3 會出現圖上沒有的值，而且每次最多只能送 3 張圖。
- **繼續用 OpenAI 的 terra**：修繕照片命中 10/10 是最好的，但它是閉源模型，不符合 DSP-080「走開源模型」的方向。

**依據**（2026-10-20～23 實測；量測紀錄在 DocuMind repo 的 `docs/testing/bedrock-vlm-eval-20261023.md`，證據在 `~/jgb-archive/bedrock-vlm-eval-20261023/`）：

- **單據、收據**：11 張真實台灣單據（Wikimedia Commons，CC 授權），每張跑 3 次、取多數。Qwen 5 欄正確率 92.6%（50/54）。只比金額和日期，Qwen 是 22/22，跟線上 terra 一樣。
- **修繕照片**：10 張，用 DocuMind repair_photo 的 prompt。命中率：terra 10/10、Ministral 9/10、Qwen 8/10、Nemotron 8/10、Large 3 5/10。
- **縮圖**：輸入 token 大約等於像素數 ÷ 1024。縮到長邊 2000 時，單據 92.6%、修繕命中 8/10，錯的欄位跟送原圖完全一樣。修繕照片每張平均從 $0.00347 降到 $0.00190，最貴一張從 $0.0079 降到 $0.0025。縮到 1500 單據會多錯 1 欄，縮到 1000 再多錯 3 欄，所以定在 2000。
- **flex**：
  - 價格：東京區價目表 flex 輸入每百萬 token $0.32、輸出 $1.61，正好是 standard（$0.64／$3.22）的一半。
  - 延遲：在東京 23:40（離峰）各送 21 張，中位數 standard 2.51 秒、flex 2.52 秒，最慢一張 5.10 對 5.32 秒。
  - 官方說明（AWS 文件 `service-tiers-inference.html`）：flex 給「能接受較長處理時間」的工作，Priority 和 Standard 會比它先處理，三種等級共用同一份 on-demand 配額。文件沒寫 flex 會慢多少，也沒寫會不會被拒。
- **每張費用**（standard、送原圖）：單據約 $0.0011、修繕照片約 $0.0034。縮到 2000 再用 flex 後，修繕照片每張平均約 $0.00095。

**已知限制**（採用時要知道）：

- 修繕照片 Qwen 只命中 8/10，terra 是 10/10。9 張不是壁癌的照片，Qwen 有 7 張標成「壁癌」。可能是 prompt 範例「（如 漏水、壁癌、龜裂、設備損壞）」把模型帶偏了，還沒拿掉範例重測。
- 單據會把買受人統編當成賣方統編；沒有單號的收據，會把統編填進單號。
- 樣本都是網路上的公開圖片，還沒用 AI 客服真實的客訴照片和單據測過；每組只有 10–11 張，不是統計結果；標準答案由主持人自己判。
- 尖峰時段 flex 的延遲沒測（業主裁示不測）。建議程式加一個等待上限，超過就改用 standard 重送一次；這個做法還沒實作。

**呼叫須知**（2026-10-20～23 實測）：

- 同一把 key（IAM 使用者 `app-jgb-ai-cs-bedrock`）已經可以呼叫 Qwen3 VL，是 2026-10-20 申請加開的。
- model ID 要用 runtime 的 `qwen.qwen3-vl-235b-a22b`。mantle 的 ID 多了 `-instruct`，價目表 usagetype 寫的是 mantle 那個。
- 單張圖片上限 3.75MB；縮到長邊 2000、JPEG 品質 92 都在這個限制內。
- temperature=0 在 Bedrock 上不保證每次輸出相同。
