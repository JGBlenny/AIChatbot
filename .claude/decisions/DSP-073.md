# DSP-073

以下為 2026-10-15 整理前 DECISIONS.md 該列「決定」欄原文

**業主 2026-10-14 撤銷 W9-2 文件禁令（AskUserQuestion 逐字：「撤銷，只放有型別的欄位 (Recommended)」）**：為站內幫手 (9-2) 謄本 PDF／照片建物件、(11-2) 發票／收據照片建手動帳單，文件擷取值可進確認卡與寫入 payload，但**只限每種文件封閉欄位表內有型別的欄位**（數字、日期、地址等，逐欄驗形狀與長度、經 `sanitize_data_piece`），卡片逐欄列出、使用者按確認才寫；**自由文字欄位仍 ⛔ 進卡片與 payload**；仍 ⛔ 進 trace／log／`agent_state`。承擔：文件內容可影響寫入值，以封閉欄位、形狀驗證與人工確認收斂。同日另裁 F9：「核可，限定專用上傳網域 (Recommended)」——`IMAGE_URL_ALLOWLIST` 可加 JGB 專用圖片上傳網域（⛔ www 或 API 主機），網址須簽章＋短期 `exp`（對新網域 `exp` 必帶）、https 不轉址、≤5 MB、由伺服端產生。
